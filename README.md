## О проекте

Исследование посвящено построению всепогодного портфеля с использованием многокритериальной оптимизации и эконометрического анализа факторной структуры доходности. Рассматриваются коэффициенты Шарпа, Сортино, Кальмара, Мартина и Омега, а также CVaR ratio.

Основные результаты:

- снижение максимальной просадки с 23–24 % до 15–16 % относительно базовой 1/N-аллокации;
- рост коэффициента Кальмара с 0,77 до 1,09;
- построение эконометрической модели связи доходности портфеля с макрофакторами (MOEXBMI, EUR/RUB, оборот организаций и импорт) с R² = 0,60.

Полный текст диссертации доступен по запросу автору.

## Быстрый запуск

Рекомендуется Python 3.13. Ноутбук и файл зависимостей сформированы и проверены в среде Python 3.13.9.

```bash
git clone https://github.com/levkazakov2002/master_degree_diploma_code.git
cd master_degree_diploma_code

python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install jupyterlab openpyxl
jupyter lab asset_selection.ipynb
```

Запускайте Jupyter из корневого каталога репозитория: пути в ноутбуке заданы относительно текущего рабочего каталога. Ячейки следует выполнять последовательно сверху вниз. Сохранённая версия ноутбука содержит результаты выполнения всех ячеек без зафиксированных ошибок.

Во время работы ноутбук обращается к сайту Банка России для получения данных по ключевой ставке, поэтому для полного повторного выполнения требуется доступ к интернету.

## Источники данных

- [Московская биржа](https://www.moex.com/) – индексы акций и облигаций;
- [Банк России](https://www.cbr.ru/) – валютные курсы, RUONIA и ключевая ставка;
- [Росстат](https://rosstat.gov.ru/) – макроэкономические показатели.

Подробные параметры загрузки и преобразования данных приведены непосредственно в ноутбуке.
