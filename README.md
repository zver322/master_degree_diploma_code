# Использование математических методов для оптимизации всепогодного портфеля

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20232640.svg)](https://doi.org/10.5281/zenodo.20232640)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Python 3.13](https://img.shields.io/badge/Python-3.13-3776AB.svg?logo=python&logoColor=white)](https://www.python.org/)

Исходный код, данные и результаты вычислительных экспериментов по многокритериальной оптимизации всепогодного портфеля на российском финансовом рынке.

Репозиторий содержит материалы магистерской диссертации и последующего исследования, подготовленного для научной публикации.

## О проекте

В исследовании рассматривается стратегическая структура всепогодного портфеля, включающего индексы акций Московской биржи, короткие и длинные ОФЗ, а также золото.

В актуальной версии используется стратегия buy-and-hold:

- начальные веса активов определяются методом многокритериальной оптимизации;
- после формирования портфеля ребалансировка не проводится;
- доходность рассчитывается с учетом изменения фактических долей активов;
- безрисковая ставка определяется на основе средней доходности однолетних ОФЗ по бескупонной кривой доходности;
- при агрегировании результатов используется одинаковый вес групп «метрика × конфигурация».

Оптимизация проводится по следующим показателям:

- коэффициент Шарпа;
- коэффициент Сортино;
- коэффициент Кальмара;
- CVaR ratio;
- Martin ratio;
- коэффициент Омега.

Дополнительно выполняются проверки устойчивости результатов к длине и шагу скользящего окна, а также к выбору временного подпериода.

## Основные результаты

Для конфигурации с четырьмя классами активов получена следующая структура портфеля:

- индекс акций - 10,4 %;
- индекс коротких ОФЗ - 54,1 %;
- индекс длинных ОФЗ - 13,3 %;
- золото - 22,2 %.

Для спецификаций 3 и 4:

- максимальная просадка составляет 16,58 % и 16,02 %;
- коэффициент Кальмара - 0,896 и 0,926;
- среднегодовая доходность - 14,85 % и 14,82 %;
- коэффициент Шарпа - 0,552 и 0,566.

Для сравнения:

- максимальная просадка равновзвешенного портфеля составляет 27,41 %;
- максимальная просадка портфеля 60/40 составляет 44,41 %;
- максимальная просадка адаптированного портфеля Bridgewater составляет 33,44 %.

Дополнительный эконометрический анализ выделяет парсимоничную модель по критерию BIC с факторами MOEXBMI, EUR/RUB, оборотом организаций и импортом. Для этой модели R² составляет 0,5061, скорректированный R² - 0,4888.

## Быстрый запуск

Рекомендуемая версия - Python 3.13.

```bash
git clone https://github.com/levkazakov2002/master_degree_diploma_code.git
cd master_degree_diploma_code

python -m venv .venv
```

Активация окружения в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Активация окружения в Linux или macOS:

```bash
source .venv/bin/activate
```

Установка зависимостей и запуск:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install jupyterlab
jupyter lab main_code.ipynb
```

Ноутбук необходимо запускать из корневого каталога репозитория. Для полного пересчета следует перезапустить ядро и выполнить все ячейки последовательно сверху вниз.

При первом запуске требуется доступ к интернету для получения отдельных показателей Банка России. Загруженные данные сохраняются в каталоге `cache`.

## Источники данных

- [Московская биржа](https://www.moex.com/) - индексы акций и облигаций;
- [Банк России](https://www.cbr.ru/) - бескупонная кривая доходности ОФЗ, валютные курсы, RUONIA и ключевая ставка;
- [Росстат](https://rosstat.gov.ru/) - макроэкономические показатели.

Параметры загрузки, очистки, преобразования и синхронизации данных приведены непосредственно в ноутбуке `main_code.ipynb`.
